# سياسة الاستخدام المقبول

**الإصدار:** 2026-08-22  
**للتواصل:** privacy@baladiguard.app

## 1. الغرض

وُجدت BaladiGuard لدعم الإبلاغ المدني بحسن نية واستجابة البلديات. توضّح سياسة الاستخدام المقبول هذه ما هو غير مسموح به في الخدمة.

## 2. العمر المطلوب

يجب أن تبلغ **16 سنة فأكثر** لاستخدام الخدمة.

## 3. الاستخدام المسموح

يجوز لك تقديم بلاغات دقيقة عن قضايا مدنية أو متعلقة بالبنية التحتية في المناطق المشاركة، وتتبع بلاغاتك، وإدارة إعدادات حسابك.

## 4. السلوك المحظور

يُحظر عليك:

- تقديم بلاغات كاذبة أو مضلّلة أو مسيئة أو تحرّشية
- رفع محتوى غير قانوني أو محتوى يستغل القُصّر أو يعرّضهم للخطر
- مشاركة رموز OTP أو انتحال هوية الغير أو محاولة الوصول غير المصرح به
- فحص الخدمة أو واجهات البرمجة أو الأنظمة البلدية أو تعطيلها
- استخدام الخدمة للرسائل المزعجة التجارية أو الإعلان أو المراسلة الجماعية غير ذات الصلة
- تجاوز حدود المعدّل أو مرشحات السلامة أو ضوابط وصول الموظفين
- جمع أو استخراج البيانات الشخصية لمستخدمين آخرين من الخدمة

## 5. الصور والموقع

ارفع فقط الصور وبيانات الموقع ذات الصلة بالبلاغ. تجنّب تضمين معلومات شخصية حسّاسة غير ضرورية عمداً متى أمكن.
